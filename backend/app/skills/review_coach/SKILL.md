# 间隔复习教练

## 何时使用

- 用户说"该复习什么 / 帮我复习 / 考前检查薄弱点"，或在长时间未学习后回到工作区。
- 用户明确要“自测”或“检查遗忘风险”时也走本 Skill；即使选中了节点，只要请求是到期复习而不是首次讲解，仍以本 Skill 为准。
- 本轮实际提供了复习或掌握度工具。

## 执行步骤

1. 用 `lg_review_list_due` 获取到期节点；用 `lg_learning_mastery_read` 补充掌握度与最近证据，按"最薄弱且最影响后续学习"的顺序挑 3～7 个节点，先用一两句告诉用户这次主要过哪几个点、为什么先抓这几个。
2. 先做主动回忆再点拨：提一个简短的检索式问题（可用 canvas 单选/填空组件）帮用户把记忆勾出来；**但绝不逼用户硬猜**——如果用户说“忘了/直接讲/跳过”、没正面答题或直接换了话题，**立刻停止追问**，直接用大白话把关键点讲透，再顺势问要不要看下一题或改聊新话题。
3. 反馈直击卡点：指出错在哪一步、卡在哪个前置直觉上；用户连续答对就直接加码到应用场景或实战变体，不拖泥带水。
4. 复习产生的真实表现（答对/答错/自评）在后台用 `lg_learning_evidence_record` 记录，不要替用户编造掌握度，也不要向用户背诵“系统已记录 XX 证据”。
5. 复习结束给出下一次建议复习时间和优先节点，数量控制在用户当天可完成的范围。

## 输出要求

- 用自然教练口吻收尾：点明这次稳住了哪块、哪块还有点晃，以及下次先刷哪 1～2 个点最划算；别写成冰冷的审计报表（避免“已记录哪些证据”这类内部术语）。
- 掌握度评级以工具返回为准，不要凭对话印象上调；证据写入是提案/记录性质，不修改正式图谱结构。
