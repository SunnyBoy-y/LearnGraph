## 逐项体验记录

### 1. 首次使用体验（新用户）
- 登录页首屏：品牌 + "账号安全登录" + 表单，无产品介绍文案（"继续学习"标题），**新用户主要靠首页空状态理解产品**。
- 注册即自动建个人工作区并进入，零配置起步 ✅（符合"首次使用不要求过多配置"）。
- 技术配置（模型/API Key）不在首流程暴露 ✅；但**未配置模型时进入 Agent 对话会中途 503**，提示"请配置模型"但无跳转配置页的引导按钮（观察项，P4）。

### 2. 操作反馈（点击→Loading→结果）
- 登录按钮 busy 态即时（"正在验证…"）✅；注册同理。
- 图谱节点选择：**1.7s 无即时反馈**（U1-1，最差项）。
- 页面路由切换：1.2-1.4s（dev 模式，未含生产对比）。
- 成功后确认：Toast/状态变化普遍存在 ✅；图谱保存有 Revision 提示 ✅。

### 3. 长任务体验
- Agent 流式：有 token 流动即"活着"；**但工具/搜索/退避期静默 30-60s+**（A1-1/A1-2）→ 这是"用户认为系统失效"的最大来源。
- 文档解析：/parse 同步阻塞（B1-8）；document-jobs 有任务状态轮询（800ms 双查询，F3.3）。
- 图谱生成：candidate-graph 走对话流，有提案条可确认/拒绝 ✅（图谱变更提案设计良好）。

### 4. 错误体验
- 构造实测：无效 token → "会话过期"（14ms）；缺 X-Workspace-ID → 422 字段缺失；模型未配置 → 503 "No model provider is enabled"，UI 翻译为"请配置模型"（可理解）；5 次错密码 → 429 锁定提示。
- **不足**：500 类错误仅通用文案（U1-3）；模型余额不足/限流等场景未实测（预算限制，标记为未测）。

### 5. 视觉/交互一致性（抽查）
- 主次按钮、禁用态、Toast 基本一致 ✅；CSP 阻断 KaTeX 字体（U1-4，公式页字体缺失）；200% 缩放未实测（标记未测）。

### 6. 可访问性（抽查）
- 表单有 label ✅、按钮有可读文本 ✅、图谱有键盘操作提示（"Press enter or space to select a node..."）✅；Tab 顺序/焦点管理未系统实测（未测项）。
