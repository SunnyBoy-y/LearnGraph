# 会话列表按需加载与性能验收

As of 2026-11-12

## 实施范围

已落实审核通过的六项方案：分页按需获取、可视窗口虚拟渲染、分场景防抖/刷新合并、减少重复分组、缓存及单项更新、首屏调度与性能记录。保留原有工作区样式和会话操作，不依赖下载完整列表打开旧会话。

### 数据接口

新增独立 `session_browser` 路由和服务，旧 `GET /sessions` 的数组、ETag 契约保持不变：

- `GET /sessions/page`：默认20条，服务端上限100条，双向游标。置顶优先、更新时间、ID完整排序；`pinned_first=false` 提供纯最近活动顺序，首页预览使用后者，避免旧置顶会话冒充最新会话。
- 支持项目、未分组、直接子级、根会话、归档、图谱、会话种类、标题/ID、创建时间范围过滤。
- `GET /sessions/{id}`：单会话完整详情，主聊天、模型配置、节点绑定和旧链接不再查全量集合。
- `GET /sessions/{id}/ancestors`：有界祖先摘要路径，最多32层，不读取模型快照/上下文JSON。
- `GET /sessions/summary`：授权一致的计数，与已加载页数量分离。
- `GET /sessions/activity`：有界日期范围的活动聚合；选中日期的会话摘要单独分页。支持IANA时区，历史夏令时不使用今日固定偏移冒充。

分页授权谓词在SQL `LIMIT` 之前执行。无活动ACL时继承工作区权限；有ACL后使用精确read权限和用户/组织/角色匹配，撤销状态与旧语义一致。列表、父校验及祖先读取都只投影摘要字段，不选择 `model_snapshot/context_capsule`。

父节点不存在、不可读、已归档或不在当前展示过滤/项目中时，匹配的子会话作为根显示。当前会话的相关分支摘要也是有界窗口；存在更多未加载分支时，不把窗口内数量冒充完整总数，不显示可能误导的全分支循环导航。其余分支仍可从侧栏独立分页或搜索打开。前端仍保留历史本地划词父映射；仅存在于本地、未在服务器记录的父关系，只能在相关摘要已加载时折叠，不会擅自迁移或修改用户记录。

### 前端加载和体验

- 真正的侧栏滚动容器作为IntersectionObserver根，120px提前量；折叠项目、子会话不提前拉内容，折叠祖先后取消后代查询订阅及在途请求。
- 每组一个续页在途锁；按ID去重。失败保留现有数据，只在底部提供重试，不自动无限重试。单次分页请求12秒超时，成功请求无人工等待。
- 每组最多10页正常窗口（200条），支持向上补回已淘汰页；新增会话和已选记录使用额外小型有界集合，不持续积累完整历史。
- 只挂载可视行和上下8行缓冲。菜单、重命名和焦点所在行额外保留；支持方向键、Home/End定位，避免失焦导致行卸载。
- 零尺寸的隐藏抽屉使用行高兜底，避免所有行塌为零高度后形成测量/渲染循环。
- 保存工作区滚动位置；数据尚未恢复到足够高度时不以被浏览器夹到0的位置覆盖原值。追加、前后换页按存活行锚点恢复。
- 搜索保留250ms请求防抖，中文组词期间暂停请求；文字输入和普通点击不加通用防抖。
- 后台会话刷新采用200ms固定合并窗口，不采用持续事件可无限推迟的尾随防抖；切换工作区/注销时清理待执行刷新。
- 改名、置顶、创建同步更新正确的详情/摘要缓存表示。新增会话有最多20条的作用域缓存覆盖，避免创建前发出的迟到picker响应把新会话隐藏。
- 按项目一次分组，不为每个项目重复遍历整个会话集合。只修改受影响的本地树节点。
- 会话文件、侧边对话、导师过程、语音调试面板、搜索弹窗按需加载。首次未打开的折叠上下文栏不挂载重型内容；已打开内容保留以免中断在途会话。
- 主聊天、图谱绑定、文档对话、原生问题提示、首页最近会话和活动日历均不通过全量会话请求取得当前会话。记忆管理等旧页面继续保留旧接口兼容，并未宣称对整个仓库所有集合完成分页迁移。

批量管理不再默认选中所有项目，避免懒加载情况下误删未展示内容。“全选已加载”明确不代表全工作区；显式选择项目仍按服务端删除影响确认处理。

## 合成基准

运行环境：本机SQLite内存库；分别插入1,000/10,000条确定性合成会话，每条快照和上下文各约1KB。每种操作3次，中位数。比较数据库查询与JSON序列化，不包含真实HTTP、认证、中间件或用户网络，不代表生产P95。

| 合成会话数 | 原全量查询+序列化 | 新20条分页+序列化 | 原响应字节 | 新响应字节 |
|---|---:|---:|---:|---:|
| 1,000 | 30.11ms | 2.12ms | 2,575,891 | 9,025 |
| 10,000 | 338.63ms | 3.54ms | 25,768,891 | 9,025 |

复现：在backend目录运行 `uv run python scripts/benchmark_session_browser.py`。脚本只创建独立内存库，不连接应用数据库。游标增加筛选契约后字节数可能有少量变化，应以再次运行的结果为准。

## 上线与未覆盖边界

前后端应一起更新并重启。新增索引由后端启动迁移执行；本轮未修改真实应用数据库，也未提交或覆盖工作区其他已有改动。

尚未在生产PostgreSQL、实际数据分布/ACL规模、真实网络及Electron/Tauri原生窗口下做终验；数据库排序列变化不是一致性快照，前端ID去重和后台校准仍必要。生产应记录冷/热首屏、续页P50/P95、请求量、长任务、DOM和内存，不能用合成3.54ms作为用户网络时延承诺。

安装新增虚拟列表依赖时npm报告40项依赖安全告警（含2项critical）。本轮没有执行自动audit fix或擅自升级其他依赖，也未做完整安全归因，需要独立复核。
