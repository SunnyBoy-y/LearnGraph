# 任务模板

> 复制本文件，把文件名改成 `任务_P0-A_xxx.md` 的格式，再按下方填补。
> 开头必须先保留一个「元信息块」，供多窗口协作时一眼判断能否并行。

## 元信息块

```text
并行性   : 可并行 / 不可并行          <- 决定是否可落地到 01_可并行/
状态     : 待开始 / 进行中 / 已完成
主要文件 : （列关键的 1-5 个文件路径）
依赖     : （无 / 依赖 P0-A 等，写清楚必须先等谁落盘）
口音标注 : 无 / 需要一个口音的标注（见 docs/README 或 ROADMAP 规范文）
```
