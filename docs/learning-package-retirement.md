# 学习包功能下线

日期：2026-11-13

## 变更边界

- 聊天画布不再挂载学习包，不再展示标题、目标卡、教材预览或展开/收起入口。
- 节点会话保留图谱绑定、当前节点、普通问答、追问与会话草稿；空会话恢复普通开场界面。
- 图谱与右侧栏不再传递学习包打开标记；移除图谱中的内容准备入口及任务模型设置中的教学包生成项。
- 学习计划的知识讲解继续走普通对话；练习、测评与复习走现有练习中心。
- 旧 `/learn/nodes/:nodeId` 书签不再读取学习包，优先返回原会话，否则返回图谱；存在 graphId 时保留图谱定位。
- 原生渲染器不再导航到旧学习包页。
- 后端不再注册 `/api/v1/learning-pages` 路由，不再在工作线程中轮询自动构建策略。
- 队列遇到既存的 `learning.package.build`、`learning.package.grade` 时取消该调度任务，不执行生成/评分处理器。
- 两条聊天提示词组装路径均不再注入历史学习包；授权节点/文件上下文、概念分支及记忆逻辑保留。

## 数据保留

未删除数据库表、迁移、学习包、构建检查点、答案、成绩、掌握度或历史消息。旧服务及组件保留为历史实现，但已从生产路由与调用入口断开；生产构建只包含旧地址重定向组件，不再包含学习包页面分块。历史模型设置仍接受原有校验，避免破坏备份导入兼容性。

取消队列调度并不表示抹除学习记录。部署时须重启全部后端及 worker，避免仍运行旧代码的进程继续执行已发出的模型请求。本次未对真实用户数据库执行清理或任务取消。

- 后端相关测试：51 项通过，覆盖旧 API 返回 404、不解析模型、队列取消、不调用构建/评分处理器、贴图索引任务保留，以及历史学习数据与图谱文件夹回归。
- 针对修改文件执行 oxlint：0 error，20 条现有 React hooks/Fast Refresh 警告，未扩展本次变更处理范围。
- Windows Chromium 本地验收页 `graph-sidebar-qa.html`：绑定节点的聊天区无学习包 DOM/展开提示，输入框与节点绑定保留；初始化无写操作；聊天区域裁切审计 `ok=true, cut=0, hidden=0`。

浏览器验收使用项目既有的本地模拟数据页面，不代表已部署到线上或已验证真实账号中的模型请求。
