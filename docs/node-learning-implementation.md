# 图谱节点学习升级：实现与验证

2026-09-17。本次为已有 LearnGraph 项目增加业务实现；没有调用外部模型或生图服务。

## 使用入口

后端启动时按现有迁移流程创建七张学习表，版本号为 v1.9.0。现有 SQLite 启动备份逻辑继续生效。

1. 打开已发布图谱，点击右上角「内容准备」。
2. 开启「自动准备新节点」。可选择保持接下来三个未开始节点的准备窗口，或批量准备全部符合条件的新节点；单独选择是否生成插画。
3. 开启后新增的节点获得本轮资格。开启前的节点、旧轮次节点、已经提问或开始学习的节点不自动补建。
4. 点击节点的学习按钮进入 `/w/:workspaceId/learn/nodes/:nodeId`。旧节点可由用户主动点击「创建学习页」；这不改变自动预构建的筛选规则。
5. 教材任务、训练实验、正式测评分别保存。正式测评从独立初始状态开始；通过后回到图谱可看到个人金色边框和成绩。

根节点不参与自动准备，允许用户主动生成概览学习页。候选图谱需先审核发布。

## 自动生产管线

每个节点有一条持久队列任务，依次推进七个检查点：

1. 教学蓝图：学习目标、章节结构、时间、实验意图和可选插画意图。
2. 图文教材：结构化章节、结论、带说明的 SVG、可选自包含 HTML 演示。
3. 实验规则：有界变量、状态名称和单位、动作前提与结果、目标条件及可执行参考路径。
4. 互动小剧场：模型生成独立 HTML/CSS/内联 SVG 场景，通过系统 `__lgSubapp` SDK 接收状态、发出 `learning.action`。小剧场不获取私有评分规则。
5. 混合试卷：单选、多选、判断、填空、简答、大题按内容组合，可加入独立实践卡。校验总分 100、选项索引和实践配置。
6. 插画：策略开启且需要插图时调用已有图片供应商和对象存储；记录用量和节点文件关联。失败则保留 SVG，并显示降级说明。
7. 发布：重验契约、实验参考路径、HTML/SVG、节点定义、开启轮次、首次学习状态及权限，然后原子写入不可变学习包并切换节点指针。

模型调用复用现有供应商配置、预算预检和用量账本。结构化输出或内容约束不合格最多进行一次修复调用；网络失败直接进入可重试状态。长任务续租，阶段结束才保存检查点。关闭策略取消当前自动任务，保留已经发布的包。

如果进程在远端调用期间中断，恢复时保留「结果未知」失败状态，不静默重复付费调用。用户可以在「内容准备」重试失败阶段或取消运行任务。主动进入学习时可以接管正在进行的自动构建。

## 学习与测评

教材使用已有 Markdown 渲染器，提供目标、章节目录、图注、小结和可勾选阅读任务。实验优先展示模型生成的小剧场，同时提供原生操作按钮、变量状态、操作记录和重置入口。两种操作入口都经过同一个服务端状态机。

学习进度按用户与学习包保存，带修订号防止并发覆盖。答卷按尝试锁定版本，自动保存，保留本地未同步草稿。交卷是幂等操作；评分由后台继续执行，离开页面不会取消。

客观题使用服务端确定性评分；简答与大题按私有量表交给配置的模型评分，低置信度或评分中断进入待复核状态并不发放通关标记。通过条件同时包含分数线、关键题和实践必过项。结果提供逐题反馈和再次挑战入口。

正式成绩和金边按用户记录，阅读或训练完成不能发放金边。失败不增长掌握星级；重复通过同一定义不会重复增加星级。节点定义改变后，旧成绩保留为历史通关，图谱不将其展示为新定义已验证。

## 数据和权限

- `learning_package_policies`：开关、轮次、范围、图片策略、策略修订号。
- `learning_package_eligibility`：新增资格、首次提问/学习时间、当前内容指针。
- `learning_package_builds`：触发方式、持久任务、节点指纹、阶段、私有检查点。
- `learning_packages`：不可变公开页面、私有答案/量表、私有实验规则。
- `learning_package_enrollments`：个人章节与训练进度。
- `learning_package_attempts`：个人正式答卷、独立实验状态、成绩。
- `learning_package_achievements`：当前个人节点通关凭证。

读取和修改接口执行工作区、图谱授权；学习与答卷记录额外检查用户归属。后台阶段与成绩发布重新检查权限。预构建不生成聊天消息、不产生学习证据；首次提问在用户消息和学习上下文持久化时记入排除标记。

生成的小剧场使用不带 same-origin 的沙箱 iframe，禁止外部资源及网络连接，只允许白名单动作进入学习 API。宿主校验消息来源、事件类型、动作 ID，合并重复事件，在服务端保存后才确认成功。公开 DTO 不包含正确答案、评分量表、实验通关规则和参考路径。

## 2026-09-18：互动小剧场结构化输出降级

互动小剧场之前要求模型把较长的自包含 HTML 放进一个 JSON 字段。部分兼容型模型在输出上限或 JSON 模式下返回半截 JSON，导致同一阶段重复三次仍失败。现在兼容 Chat 通道与其他结构化通道统一使用容错 JSON 提取；小剧场提示词限制 HTML 体积；结构性、校验性或暂时性的小剧场生成失败时，阶段自动使用内置的自包含 `__lgSubapp` 交互模板。服务端生成的实验规则、状态机、成绩和测评仍然是权威数据，小剧场只负责展示和发起允许动作。

这意味着“互动小剧场”模型失败不再阻塞教材、实验规则、测评和最终发布。模型生成成功时仍使用模型场景；失败时学习页会保留一个可操作的文字 / 状态场景，并在构建备注中说明降级原因。截图中已经失败的旧任务需要点击“重试当前阶段”才能应用新的阶段逻辑，已完成阶段不会重做。
