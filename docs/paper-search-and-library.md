# 论文检索、原文引用与资料沉淀

## 范围

本次仅增加三个机制：论文专用搜索、搜到→读到→引用到、学习资料沉淀。不替换 AnySearch，不改变通用搜索优先级，不自动跨服务商回退，不新增完整浏览器搜索自动化。

## 使用入口

- 联网搜索页面新增「论文专用搜索」：显式选择 OpenAlex 或 arXiv，支持关键词、作者、年份、相关性/最新排序、开放获取筛选。
- 点击「读取公开正文」授权当前显示的 PDF 域名；跨域跳转需要单独批准。只读取公开 PDF，不绕过登录或付费墙。
- 点击「收藏论文」仅保存元数据/摘要；读到原文后点击「读取并收藏正文片段」保存服务端重新读取的、与引用一致的快照。不会把预览文本作为可信输入直接回传。
- 资料库不再显示独立的「论文收藏」面板；已保存论文仍保留在来源记录中，通过现有来源详情和关联弹窗查看及显式关联 Project、Goal、Graph 或 Node，不改会话绑定和掌握度。
- 搜索结果和来源详情支持 BibTeX 导出；已保存正文片段支持按 PDF 物理页定位、复制原文和引用。

## Agent 工具与路由边界

- 新增 `search_papers` 和 `read_paper`，不依赖外部 SearchProvider 是否存在。
- 两者遵循现有联网开关及路由约束：仅在 `auto`/`external` 且本轮联网已开启时暴露；`model_native`/`disabled`/`local` 不允许调用。此改动没有改变用户既有「仅原生」语义。
- 前端「自动」仍可能解析到原生路由，此时聊天继续用托管搜索，论文专用入口可由用户在搜索页明确发起；不悄悄转外部检索。
- 查询失败真实报错，不静默转 AnySearch、其他学术提供商或浏览器。
- 默认仅在论文、作者/年份/DOI 核对等任务使用论文工具，不要求所有涉及论文的问答都额外调用。
- 读取工具没有用户输入的 URL 或授权域名参数，不能由模型自行授予域名权限；复用持久化授权卡，并对公开 PDF 的初始与重定向域名逐一授权。
- 搜索页是用户主动发起的独立接口，不改聊天会话路由设置。
- 收藏与关联为明确的用户界面操作，不自动持久化搜索结果。

## 证据口径

- `metadata`：仅拿到书目信息。
- `abstract`：拿到摘要，不代表读过全文。
- `full_text`：实际取得公开 PDF 并完成文本提取，但只有返回片段算已读；保留截断标识。
- 物理页码从 1 开始，空白页不重新编号。Agent 来源链接使用 `#page=N`，复用宿主分配的引用编号。
- 保存原始 PDF 字节 SHA-256、实际返回片段、物理页 locator、抓取时间和提供商元数据；片段内容哈希与原始 PDF 哈希分别保存。
- 不自动判断同行评审状态，arXiv 明确标记为预印本。DOI 仅来自提供商返回，不凭标题或模型生成 DOI；本轮未增加 Crossref 二次核验。

## 安全与限制

- 固定学术 API 地址，ID 严格校验；公共 HTTPS 下载复用既有 IP 固定与逐跳安全检查，不向论文主机发送 OpenAlex 密钥。
- 默认 API 请求 20 秒、响应 4 MB；PDF 下载最多 20 MB、总下载预算 35 秒、解析最多 200 页、返回最多 48,000 字符且单页最多 6,000 字符。
- 不支持图片扫描型论文 OCR 或 PDF 图表理解；空正文、非 PDF、受限页面和超限内容不记为已读。
- 库内复用 `SourceRecord` / `SourceCitation` / `SourceLink`，没有数据库迁移或另建收藏表。收藏按工作区及 DOI/提供商 ID 幂等；摘要升级正文使用数据库条件更新，正文、哈希和引用组同事务提交。
- 论文收藏列表当前最多返回最近 200 条。
- OpenAlex 可通过服务进程环境变量 `OPENALEX_API_KEY` 提高可用配额；密钥不进入前端。未配置时按上游实际响应处理，不承诺无限免费。没有新增管理界面或独立计费集成。
- arXiv API 请求在单个进程内按至少 3 秒间隔节流；多进程全局限流不在本轮范围内。

## API

- `POST /api/v1/papers/search`
- `POST /api/v1/papers/read`
- `POST /api/v1/papers/save`
- `GET /api/v1/papers/library`
- `GET /api/v1/papers/library/{source_id}/bibtex`
- `GET /api/v1/papers/library/{source_id}/citations`

沿用认证、工作区隔离、来源 ACL、源记录删除与现有 SourceLink 接口。

## 官方协议参考

- OpenAlex API：https://help.openalex.org/api/
- arXiv API：https://info.arxiv.org/help/api/user-manual.html
